# tank-software-design

Уровень можно создать генератором или загрузить из текстового файла:

```java
GameWorld generated = GameWorld.random(10, 8, 15);
GameWorld loaded = GameWorld.fromFile(Path.of("level.txt"));
```

В файле одна строка соответствует строке клеток уровня. Поддерживаются символы
`T` (дерево), `X` (единственная начальная позиция игрока) и `_` (пустая клетка).
Символ `E` обозначает стартовую позицию вражеского танка.

Для случайных карт доступны перегруженные методы с количеством вражеских танков.
Вражеские танки выбирают случайное направление на каждом ходе, игрок управляется
клавиатурой. Во время хода исходная и конечная клетки зарезервированы, поэтому
танки не сталкиваются; границы карты обрабатываются как препятствия.

Карты приложения находятся в `src/main/resources/maps`. При запуске по умолчанию
загружается `maps/default.txt`, а фон игрового поля — `maps/level.tmx`.
Для ручной проверки движения и столкновений доступна карта
`maps/test-map.txt`; она имеет тот же размер 10x8, что и `maps/level.tmx`.
Карта `maps/test-map-with-enemies.txt` дополнительно содержит вражеские танки.
